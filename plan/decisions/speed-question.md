# Faster to get, or faster to judge

## The choice

An agent's part, 22 November 2026. Two proposals wait. One lists what is only in a fork before you
drop it. The other adds colour themes to the app.

The options:

- A principle (recommended). The list makes a result faster to judge, so it is built. Themes make
  nothing faster, so they are later. It costs things people like that speed nothing up, and "faster
  to judge" is argued, not measured.
- No filter. Each feature is weighed by itself. It costs an order decided again each time, with no
  line to point to.

Recommended: a principle. It says in one sentence what Silo is for, and it gives a reason to say
"later".
