# Where do computers run

## The choice

An agent's part, 25 November 2026, from the challenge of #352 (file 05) to `where-it-runs`, which polarzero
took.

The case: Silo's own cloud offers a macOS main to a user for a week. Apple's licence for macOS 26
excludes "service bureau, time-sharing" (section 2B), and allows leasing only a whole Mac to one user
for at least 24 hours, for developer services such as CI, building and testing (section 3). A macOS
main rented as a shared service is outside both (verified on Apple's PDF; a lawyer's reading is a
question for Linear, not the plan).

The options:

- Say it: a macOS computer in a cloud runs only on a whole Mac leased to one user; a shared cloud
  runs Linux computers (recommended). It costs a macOS main in a cloud the price of a whole Mac.
- Keep the earlier answer, which does not say it. It leaves a plan that reads as allowing what the
  licence forbids.

Recommended: say it. It changes nothing for the first builds, which run on your own Mac.
