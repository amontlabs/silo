# The agent is hostile

## For the owner

An agent's part, 22 November 2026. A feature lets an agent leave a note for you in the app. A
hostile agent could write a note that looks like a message from Silo and asks you to grant
something.

The options:

- A principle (recommended). Every addition is asked what a hostile agent can do with it. The
  question is asked of small features too, while security is not the current focus. It costs one
  more question that every addition has to answer.
- A decision only. The sentence still binds, as it does today. It costs the question: a feature
  designed for honest agents ships, and the hostile reading is found later.

Recommended: a principle. Asking is cheap, and the fix can wait for its stage. Not asking is how a
note becomes a way to trick you.

## Notes

The sentence is decided, in `security-framing`. The question is worded by whoever wrote the plan.

Once it is taken, `flood-never-removes-older-lines` follows from it: its writer named it in `from`,
which waits until the principle is in force.
