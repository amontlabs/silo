# The meanings of the words for an agent's work

## The choice

An agent's part, 22 November 2026. Claude Code is signed in with your subscription in main, and one
of its replies asks to run `npm install`. Three words name that scene: the agent program, the tool
call and the login.

The options:

- Agent program said by what it does (recommended). "A program that runs a model and carries out
  what it asks for: Claude Code, Codex and the like." It is read as any program that does this, so
  one built on an agent SDK is an agent program too. It costs a wider word than the vendors'
  programs Silo reads today.
- Agent program said by examples. "Claude Code, Codex and the like." It is read at once. It costs an
  answer each time someone asks whether a new vendor's program, or their own, is one.

Recommended: said by what it does. A meaning that is only examples leaves the edge of the word open,
and "run" is defined through it. The other two are read as written either way: a tool call is "one
thing a turn asked for: a command, a file edit, a search", and a login is "a sign-in to a model
provider, by subscription or by key".

## Notes

The record's word list (section 2) carries no mark. A word's meaning is in force only where a
line marked Decided or Agreed, or settled in STATE, holds it. What this decision sets is the
word list's own meaning, which replaces the word in `words.json` when taken.

- agent program: no marked line holds its meaning.
- login: no marked line holds its meaning.
- tool call: in force as "One thing the reply asked for.", the chain's own words (record 5.2, Agreed, l.598).
