# What a member sees of what the company set up

## The choice

An agent's part, 24 November 2026. A company's device management installs Silo on 30 Macs, with a
rule set and an extension that sends the hash of each record's last line, and the spend summaries,
to the company's log tool. A developer opens Silo.

The options:

- All of it, marked as managed (recommended). Each managed rule set, extension and setting shows
  with who manages it. An extension that sends any part of the record shows where it sends and
  what. It costs a company that wanted to watch without saying so, which Silo should not serve.
- Only what the member can change. It costs `yours-to-know`: what is sent about a person's agents
  is theirs to know.

Recommended: all of it. macOS itself shows that a Mac is managed and what each profile does.
Monitoring of employees in the European Union has to be disclosed in any case.
