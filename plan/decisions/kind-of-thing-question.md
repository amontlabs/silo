# One kind of thing

## The choice

An agent's part, 22 November 2026. Checkpoints are built for Linux computers first. Someone proposes
to ship them, and to give macOS computers something different later.

The options:

- A principle (recommended). The feature says whether it is the same on macOS and Linux, and which
  platform forces the difference if not. A feature that is easy on one system may then wait for the
  other. It costs one more question that every addition has to answer.
- A decision only. The sentence still binds, as it does today. It costs the question: a difference
  between systems can arrive because it was easier, not because a platform forced it.

Recommended: a principle. You run a macOS main with Linux forks, so you are the first to meet any
difference.

## Notes

The sentence is in force: `one-kind-of-computer`. The question is worded by whoever wrote the
plan.
