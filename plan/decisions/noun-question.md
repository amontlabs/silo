# Does it need a new noun?

Question 2 of the design record's section 12, marked Notes. In full: "Everything is a computer or is
defined through one (a checkpoint is a computer at a moment, a fork is a copy, a recipe is how to
make one, a task is a command in one with an end). Or it is something Silo knows (a fact, a
report, an opinion, with the classifier that gives it), or something Silo does (a rule, a
precaution). A receipt, an alert and the timeline are made from those."
