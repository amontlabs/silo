# How your own agent programs, providers and habits work inside your Silo computers

## For the owner

An agent's part, 22 November 2026. On your Mac you use Claude Code with three MCP servers and twelve
skills, and Codex, and your repositories are in ~/code. You install Silo.

The options:

- The first run moves you in (recommended). It lists what it found, you tick what to bring, and main
  starts with it. You sign in to each program again inside main. It costs Silo the work of knowing
  where each agent program keeps its settings and skills, and of keeping up as vendors change them.
  A program Silo does not know is not found, and you bring it in by hand.
- You move in yourself. Main starts without your setup, and a guide says how to install each program
  and copy its settings. It costs you that setup, program by program, before the first agent works
  in main.

Recommended: the first run moves you in. You asked for good onboarding, and the first agent in main
should work with what it had on your Mac.

## Notes

The owner said this: everyone has their own agent programs, providers and habits; how does all of
it work inside their Silo computers? The owner wants good onboarding for it.

How logins come in is part of `logins` and `reaching-a-computer`, and is open.
