# What does first run do where it could fail

## For the owner

An agent's part, 22 November 2026. You install Silo on a MacBook with 30 GB free, and the Wi-Fi
drops halfway through the download of macOS.

The options:

- Check first, stop clearly, go on where it stopped (recommended). Silo checks disk, memory and
  network before it starts, and tells you up front if the disk is too small. When the Wi-Fi drops,
  the download goes on from where it stopped. Where Silo would have to guess, such as which agent
  program you use, it asks. It costs a few questions and a check before anything starts.
- Start at once with defaults. Silo picks for you and starts downloading. It costs a main that can
  turn out wrong later, when an agent fails on a choice you never saw.

Recommended: check first. A download can always break, so what the first run can promise is to say
why and go on, never to leave a main half made.
