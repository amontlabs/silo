# How does the user get from a run in Silo's window to its conversation

## The choice

An agent's part, 22 November 2026. Silo's window shows that a run of Claude Code in the fork try-bun
stopped and needs you.

The options:

- One action, the right conversation (recommended). A click opens your own terminal app in try-bun,
  in the run's folder, with the conversation taken up again. It costs Silo recognising each
  program's conversations. When it cannot, the terminal opens in the computer and the folder, and
  says so.
- Silo shows the way, you open it. Silo shows the computer's name, the folder and the command to
  type. It costs a copy and a paste each time a run needs you.

Recommended: one action. Going from a run that needs you to its conversation is what Silo's window
is for, so it should take one step.
