# From a run to its conversation

## The choice

An agent's part, 22 November 2026. Silo's window shows that a run of Codex in the fork try-bun
stopped and needs you. One click opens your terminal app in try-bun, in the run's folder, with that
conversation taken up again.

The options:

- Build it (recommended). One click takes you from the run to its conversation. It costs Silo
  recognising each conversation from the program's traffic to its model provider, which is still to
  find out. When it cannot, the terminal opens in the computer and the folder, and says it found no
  conversation.
- Leave it out. Silo shows the computer and the run, and you open the terminal, find the folder and
  take the conversation up yourself. It costs those steps each time a run needs you.

Recommended: build it. Going from a run that needs you to its conversation is what Silo's window is
for.
