# Moving in from your Mac

## The choice

An agent's part, 22 November 2026. On your Mac, Claude Code has three MCP servers and twelve skills,
and your repositories are in ~/code. The first run lists them, you tick what to bring, and main
starts with them. Paths in your settings still work, since main's user has your user name. You sign
in to each program again in main.

The options:

- Build it (recommended). Your setup comes into main on the first run. It costs Silo knowing where
  each program keeps its settings and skills. A program Silo does not know is not found, and an app
  a recipe cannot install, such as one installed by hand, you install yourself.
- Leave it out. Main starts without your setup, and you copy each setting, skill and repository
  yourself. It costs that work before your agents work in main as they did on your Mac.

Recommended: build it. Keeping your agent programs and habits is what this part of Silo is for.
