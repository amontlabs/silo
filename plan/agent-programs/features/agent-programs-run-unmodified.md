# Your agent programs in a computer

## The choice

An agent's part, 22 November 2026. You use Claude Code and Codex. Next month you try a new agent
program Silo does not offer: you install it in main with its vendor's installer, and it runs.

The options:

- Build it (recommended). Any program runs unmodified. For each program it offers, Silo keeps a
  description of where it keeps its login, its sessions and its skills. It costs keeping that list
  up with each vendor, and a program Silo does not know gets nothing of what the description allows.
- Leave it out. Agent programs still run in a computer, since it is a whole machine, but Silo knows
  nothing about any of them. It costs the features that need that knowledge: setting up a program on
  the first run, keeping its login out of a fork, and taking its conversation up again.

Recommended: build it. It is what lets you keep the programs you already use, and every other
feature of this part stands on it.
