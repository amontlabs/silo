# A trial on the past

## The choice

An agent's part, 22 November 2026. You import Push check, which would hold pushes it finds risky.
Before installing it, you run it in a fresh computer on the last week of main's record. It would
have held 4 of 37 pushes, 3 of them ones you had let through, and it tried to reach a host its list
did not name.

The options:

- Build it (recommended). You see what an extension would have done before it can do anything. It
  costs what the extension spends on a week of work, in tokens if it asks a model, and an extension
  can behave differently on the past than live, so a trial shows what it did then and promises
  nothing.
- Leave it out. You learn what an extension does once it acts on your computers. It costs the first
  wrong holds and alerts, on real work.

Recommended: build it. Spam filters and fraud checks are tried on past data before they go live for
the same reason, and Silo already keeps the past.
