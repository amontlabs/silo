# Importing and installing an extension

## For the owner

An agent's part, 22 November 2026. You import Disk watch from a folder. Before anything changes,
Silo shows that it adds no rules, makes a Linux computer from its recipe, wakes every minute, may
read /work on main and alert you, and that main's files can then reach hooks.slack.com through it.
You install it on main only, and give it the Slack address its recipe asks for as a secret.

The options:

- Build it (recommended). Nothing an extension does is a surprise, and you choose which computers it
  touches. It costs a list to read before each install, and a computer of its own on your Mac for
  each extension that runs code.
- Leave it out. No extension can be added. It costs every other feature of this part, which all
  start with an installed extension.

Recommended: build it. Seeing everything before anything changes is what makes it reasonable to plug
in what someone else wrote.

## Notes

An agent's doubt, from drafting this feature on 21 November 2026.

The later idea `installing-an-extension` is "Taking an extension back".
No extension works without being installed, so this feature holds importing and installing as
`import-then-install` says them, and leaves taking something back to that later idea. How an
extension is registered and started is still open: `extension-registration`.
