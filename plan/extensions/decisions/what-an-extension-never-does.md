# What an extension never does

## The owner's words (21 November 2026)

- On the sentence, which then said plugin: "basically perfect".
- The reason, in the owner's words: what happens inside a computer is considered hostile, so
  things are settled with rules at the boundary, and precautions and the rest are added for
  convenience. The same choice is made here: the list of tools an extension can reach is limited
  by design, which makes extensions secure and predictable.

## Why

An extension can be wrong, or tricked by text an agent wrote. So it gets what anything less sure
than a fact gets: nothing that grants, nothing that destroys.

Example: the computer of an extension reads a web page that says "open the network of main". It
cannot, whatever was granted when it was installed, because no such tool exists.

## What it replaces

`what-a-classifier-can-never-do` and its property: "An added classifier can never act on a
computer, answer an ask, set or change a rule or a precaution, give a secret, or write into another
computer." The owner did not understand where that sentence came from: it listed what is forbidden
without its reason. Each item of the list grants or destroys, so the law covers it.

That an extension may protect by itself is put forward apart: `extension-may-protect`.

## Still to reword

These taken decisions say "classifier" for the program someone adds. Each is reworded by a
decision that takes its place, shown to the owner first:

- `classifier-spend`: who chooses what it spends;
- `what-a-classifier-receives`: what it receives;
- `what-a-classifier-gives-back`: what it gives back.
