  silo tool call we can confidently know what it means and improve the Ux for it as in display it

- An agent: the answer says what the record keeps, because a view can show only that. How a view
  shows it is settled when that view is built.
- An agent: an agent's tool call is the opposite case (`tool-calls-from-traffic` in the part
  `traffic`). Silo reads it out of the model traffic, in the provider's format. A tool of an
  extension is Silo's own, and Silo carries out each use of it.
- An agent: what a line holds beyond this, such as what a read returned, is settled when each tool
  is built (`extension-tools`).
