# How an extension's opinion is kept

An agent's part, from redrafting the features on 21 November 2026.

`what-makes-a-classifier`, proposed, says a classifier is an extension that gives a value from a
fixed list. `extension-tools`, taken, says an extension uses only tools that read, show or
protect. None of them writes an opinion. `opinions-computed-again`, taken, says a classifier's
opinions are kept and computed again when it improves.

So the plan does not say how the value a classifier gives becomes an opinion kept beside the
record: through a tool of its own, as what one of the three kinds of tool gives back, or in
another way. The features that give opinions (`opinions-beside-the-record` and those after it)
wait for this.
