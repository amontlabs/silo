# An extension that executes anything ships a computer

## The owner's words (21 November 2026)

- The owner asked for something specific and generic that says at which point an extension can
  do something on the machine.
- Then: if something is executed, what the extension ships is a computer. Its manifest declares
  the computer through its recipe. Secrets and the rest then fit in naturally, and importing the
  extension shows the computer that will be made.
- An extension that calls a model is one extension among others. It brings what it needs for
  that, and nothing in the design is about models.

## The line

One question settles it: is anything of the extension executed?

- Executed means the author wrote what the machine does. A program can do whatever its machine
  lets it do, so it runs in a computer, where rules at the boundary set what it can reach.
- Not executed means Silo only reads it and picks among choices Silo itself offers, as with
  rules. It can do nothing by itself.
- In Silo's own process an extension would have what Silo has: every computer, every secret, the
  record.

## What it replaces

`where-a-classifier-runs` said: "A classifier that is only data needs no computer. Code or tools
means a computer." The line is now whether something is executed.

## What it costs

One computer for each extension that executes something.
