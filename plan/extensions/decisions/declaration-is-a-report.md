# A declaration is a report

## The choice

An agent's part, 27 November 2026. polarzero: "let your agents do anything without approvals
inside the vm but it has to declare a set of transactions and hold/block them if your balance
decreases". An agent is about to rebalance a position in twelve transactions. Asking you twelve
times teaches you to click yes: the page of the part `boundary` says that people who are asked
often stop reading. Asking nothing leaves only "did value leave", which is true of every swap.

The agent is hostile (`security-framing`), so what it declares proves nothing. If a matching
declaration let a transaction pass, the agent would declare the theft and pass. So a declaration
does one thing: it puts a set in front of you. Your yes is what allows
(`grant-needs-a-fact-or-you`). After it, each transaction is a fact at the boundary, and the
extension compares it with the set you approved.

The options:

- A declaration is a report, and you answer it once (recommended). Twelve asks become one. The
  extension never hears from the agent: it reads the declaration in the record, like any report,
  so `extension-tools-for-agents` keeps its answer. It costs a new word and a way to write a
  report from inside, through the `silo` command a computer already has
  (`computer-reads-its-record`).
- No declaration. Every transaction that moves value is held. It costs your attention, and the
  agent cannot say in advance what it will do.
- The agent talks to the extension. It costs a channel from the computer to the code that
  protects it, which `extension-tools-for-agents` proposes to refuse.

Recommended: a declaration is a report, and you answer it once.

## The bad paths

An agent's part.

- You answer no: the declaration stays in the record as refused, and nothing it names is approved.
- The hold reaches its limit with no answer (`hold-limit`): the same as no.
- The agent declares again: a new declaration is a new request, held and asked like the first.
- The agent declares a hundred times: the asks join into one per computer, as `asks-for-a-burst`
  proposes for any held request.
- No precaution holds declarations on that computer: the declaration is written in the record
  and approves nothing.
