# Reading is a grant

The owner said the first sentence. The second is agreed, from the text on an added classifier's
access: "Reading the record of the computers you name. This is a grant."

That text said the grant was made "here by you". It is cut, because a rule set in advance can now
make it. It also said "those computers", the computers you name; here it says "the computers it
reads".

How such a grant is made, what it includes and how it is taken back is open:
`classifier-read-grant`. Which part of the record it covers: `read-grant-names-its-part`.
