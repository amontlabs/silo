# A grant to read names its part

## For the owner

An agent's part, 22 November 2026. You install Disk watch on main. To do its job it needs the file
lines of main's record. Main's record also holds every model call: the tool calls your agents'
models made and what came back to them, such as the contents of the files they read.

The options:

- Each read names its part (recommended). Disk watch's list says "file lines of main", you see that
  when you import it, and it never gets main's model calls. It costs a longer list to read when you
  import, and an extension that later needs more asks for it in a new version.
- A read covers the whole record of a computer. Disk watch gets everything recorded about main. It
  costs your conversations: every extension that reads main can send them to any host its computer
  may reach.

Recommended: each read names its part. It is the list of scopes you asked for, like a GitHub
token's, and an extension then holds only what its job needs.

## Notes

In the manifest (`extension-manifest`), the tool that reads names its part.
