# Where a classifier runs

This replaces two older statements: that an added classifier "runs in a computer of its own,
never in one it watches", and the reason given for it, under "Why it runs in a computer":

> It reads text written by the agents it watches: file names, commands, web pages. That is the
> path by which an agent could give it instructions. In a computer it has the same boundary as
> everything else. An added classifier has a receipt like any agent.

The last sentence of that reason, on a receipt, is not answered by what replaced it. It is kept
here so that it is not lost.
