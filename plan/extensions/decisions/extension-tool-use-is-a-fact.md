# An extension's use of a tool is a fact

- An agent, on 21 November 2026: `extension-points-at-the-record` says that an alert from an
  extension points at the lines of the record that led to it. In the fifth film, disk watch wakes
  on a time, reads `/work` on main and alerts. Nothing put that read in the record, so its alert
  had no line to point at. With this decision it points at "disk watch read /work on main".
- polarzero, the same day: "I agree with this btw, since this crosses the boundary. I feel like by
  design this would have been caught anyway like no reason it doesn't get caught, except that
  since it's a silo tool call we can confidently know what it means and improve the Ux for it as
  in display it with more knowledgable information". What follows "except" is put forward in
  `what-the-record-keeps-of-a-tool-use`.
- An agent: it is a fact by the meaning of the word. The use goes from the extension's computer to
  Silo, so Silo saw it itself, from outside that computer.
- An agent: the entries say "use of a tool". `tool call` is the word for what a model's reply
  asked for.
- An agent: `file-reads` in the part `record` still holds. It leaves out what the programs of a
  computer read inside it. Here one line is written for each use of a tool, however many files
  the tool read.
- An agent: an extension that wakes every minute writes 1,440 of these lines a day. How a view
  folds lines that repeat is settled when that view is built.
