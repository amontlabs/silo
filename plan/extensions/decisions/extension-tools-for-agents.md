# Tools for agents

## For the owner

An agent's part, 22 November 2026. Someone writes Docs search, an extension that keeps an index of
your team's documents and would give the agents in main a tool, search_docs. To keep its index
fresh, it also reads main's record.

The options:

- No (recommended). Extensions watch and protect, and serve nothing to agents. Docs search runs as
  an ordinary computer, and you let main reach it the way you let main reach any other computer. It
  costs two steps instead of one install, and tools for agents are not shared the way extensions
  are.
- Yes, named in its list. Installing Docs search opens a way from main to its computer, shown before
  you confirm. It costs a way in to what watches main: an agent can send anything to an extension
  that may also read or hold main's work, read its replies, and try what gets past it before it
  acts.

Recommended: no. What watches a computer should not answer to it, and agents can already be given
tools through a way that your rules cover.

## Notes

Extra tools that a piece would offer to agents in other computers are not designed, and a route
between computers is a channel.
