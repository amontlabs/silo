# A grant to read another computer's record

The question as the design record asks it: how do you grant an added classifier access to another
computer's record, which views does that grant include, and how do you revoke it?

That reading is a grant, and that a rule set in advance can give it, is taken:
`reading-is-a-grant`. Which part of the record it covers is put forward in
`read-grant-names-its-part`.
