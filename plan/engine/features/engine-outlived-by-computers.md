# Computers that outlive the engine

## For the owner

An agent's part, 22 November 2026. An agent is three hours into a job in main when Silo's engine
crashes.

The options:

- Build it (recommended). The job goes on, under the rules main had, because each computer is kept
  by a small program of its own. A fork you ask for meanwhile waits until the engine is back. It
  costs one extra program per computer, whose memory is not measured yet, and while the engine is
  away you cannot pause or stop a computer through Silo.
- Leave it out. Computers stop when the engine does. It is simpler and uses less memory. It costs
  the agent's job at every crash of the engine.

Recommended: build it. A fault in Silo should not end work that was going well.
