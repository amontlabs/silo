# Whether a request waits

| | Rule | Precaution |
|---|---|---|
| Synchronous: the request waits at the boundary for the answer | any kind | protective only |
| Asynchronous: nothing waits; the trigger is something already seen | any kind, except allow, hold and deny | protective only, except hold and deny |

A fact about the request at the boundary is known on the spot. An opinion takes time: either the
request waits for the classifier, or the opinion comes after and only the computer is left to
act on.
