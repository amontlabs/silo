# What does Silo show before a set of rules is switched on

## For the owner

An agent's part, 22 November 2026. You switch the set "web work" on for main. Main already reaches
github.com. The set also allows registry.npmjs.org.

The options:

- Show what is new (recommended). Silo shows one line: main could then send anything it can read to
  registry.npmjs.org. A switch that grants nothing new shows nothing. It costs one look, only when
  something opens.
- Show the whole set every time. You see all its rules before each switch. It costs attention: the
  same list each time is a list you stop reading.
- Switch at once. The set applies, and you can read it afterwards. It costs you the moment to say no
  before a way out opens.

Recommended: show what is new. People who are asked often click yes, so the step should appear only
when it has something to say, and it should also appear when switching a set off opens something.
