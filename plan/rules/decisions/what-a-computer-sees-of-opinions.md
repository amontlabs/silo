# What a computer may see of the opinions and precautions about it

## The choice

An agent's part, 25 November 2026, from the challenge of #351 (recommendation 23) to
`where-precautions-live`, which polarzero took.

The case: in the morning an agent in main asks the record "what did the other run change last
night", through `silo` (`app-as-text`). Which run changed a file is always an opinion (`the-chain`).
Under the earlier answer a computer sees no opinion about itself, so the agent gets file changes
with no run attached, and has to guess. That guess is what `app-as-text` exists to prevent.

polarzero's words of 19 November 2026, kept in the earlier decision's notes, are about what raises
an alert or a pause: it lives outside the computer, and the agent should not know what can trigger
it. The descriptive opinions trigger nothing.

The options:

- A computer sees the descriptive opinions that ship with Silo about its own record, and nothing of
  precautions (recommended). It costs one line between two kinds of opinion: one that describes
  the record, and one a precaution reads. A shipped opinion that a precaution also reads is seen
  only as its description, never as what it triggered.
- A computer sees nothing, as the earlier answer says. It costs the case above.

Recommended: the descriptive opinions, never precautions. It keeps what polarzero asked for, that an
agent does not learn what triggers an alert, and lets an agent read who changed what.
