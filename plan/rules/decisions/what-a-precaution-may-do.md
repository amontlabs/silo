# What a precaution may do

The first sentence is polarzero's, settled after the rest. The other two are agreed as they
stand. The list is not the whole of it: `kinds-of-action` files taking back a secret and closing
a network or any other channel as protective, so a precaution can do them too.

## Examples of precautions

A run with no activity for a set time; writes that no run accounts for; a change to a file that
looks like a credential; a budget on a run; a classifier's opinion that an agent is working
against you: the precaution pauses the computer and alerts you.

## Raised on 22 November 2026, by an agent

A precaution closes main's network when a classifier says "not safe". `kinds-of-action`, taken,
files closing a network and taking back a secret as protective, so a precaution can do both. The
answer here lists four actions and leaves those two out, and someone who builds from this answer
alone would make them impossible. An answer that covers every case: "A precaution may take any
protective action, and no other. It pauses and never stops." No decision replaces this one yet.
