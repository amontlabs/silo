# What a rule allows, shown when it is set

## The choice

An agent's part, 22 November 2026. You allow api.github.com on main, and Silo says: anything main
can read can be sent there. Then you switch on the set "web work", and Silo shows that it would also
let main send to registry.npmjs.org.

The options:

- Build it (recommended). Each rule says the worst it allows, and a set shows what it grants before
  it applies. It costs a sentence to read on every rule, and Silo must get each sentence right.
- Leave it out. Rules are set as they are, one by one. It costs the plain statement of what you just
  opened, which you otherwise have to work out yourself.

Recommended: build it. Silo does not choose your rules, so the least it owes you is what each one
allows.
