# Opinions and classifiers

What a classifier, or you, think about the record.

## For

To say what happened in a computer (which run did it, what can be rebuilt, what looks wrong)
without letting a judgement pass for what Silo saw.

## Why it is so

- **An opinion can be wrong, so it is kept apart** (`opinion-stored-apart`,
  `opinions-computed-again`).
- **A classifier's opinion acts only through a precaution** (`opinion-acts-through-a-precaution`),
  which you set, in the part `rules`.
- **Your own opinions** (`your-opinion-kept-as-given`).

## One example

A classifier reads the record of main and gives the opinion "stuck" about a run. The opinion says
whose it is and stays apart from the record. The classifier does nothing to the run. If you set a
precaution on that opinion, the precaution may pause main and alert you.
