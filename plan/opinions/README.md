# Opinions and classifiers

What a classifier, or you, think about the record.

## For

To say what happened in a computer (which run did it, what can be rebuilt, what looks wrong)
without letting a judgement pass for what Silo saw.

## Why it is so

- **An opinion can be wrong, so it is kept apart** (`opinion-stored-apart`). Built on as truth, an
  error would pass into every later opinion. Kept apart, a better classifier replaces a worse one
  and the opinions are computed again, with nothing to migrate (`opinions-computed-again`).
- **A classifier only gives opinions** (`classifier-never-acts`). What an opinion may lead to is
  said by a precaution you set, in the part `rules`.
- **Your own opinion is kept as you gave it** (`your-opinion-kept-as-given`).

## One example

A classifier reads the record of main and gives the opinion "stuck" about a run. The opinion says
whose it is and stays apart from the record. The classifier does nothing to the run. If you set a
precaution on that opinion, the precaution may pause main and alert you.
