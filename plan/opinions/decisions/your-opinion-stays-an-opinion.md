# Your opinion stays an opinion

That an opinion you gave is kept as you gave it is in force: `your-opinion-kept-as-given`. What
this decision adds is "it is still an opinion: it can be wrong".

The design record's own wording, which this sentence is put forward from:

- "It is given, not computed: Silo keeps it as you gave it until you change it, and computing the
  other opinions again never deletes it."
- "It is still an opinion: it can be wrong, and no rule reads it."

That no rule reads it follows from `rule-reads-only-facts` in the part `rules`.
