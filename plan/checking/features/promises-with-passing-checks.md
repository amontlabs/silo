# Promises with passing checks

## For the owner

An agent's part, 22 November 2026. The site has a page of what Silo promises. Each line gives one
promise, how it was checked and what was not, the version of Silo and the date. Each release runs
the checks again and updates the page.

The options:

- Build it (recommended). It costs upkeep: the page changes with each release, and a promise comes
  off it when its check fails.
- Leave it out. The site says what Silo does, with no check shown next to it. It costs trust:
  readers take Silo's word for it.

Recommended: build it. People who give agents full access want to see what was checked, and the page
is written by the checks themselves.
