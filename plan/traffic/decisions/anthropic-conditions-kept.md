# Does Silo keep Anthropic's two conditions for a product that preinstalls or runs Claude Code

## For the owner

An agent's part, 22 November 2026. Silo's recipe for main fetches Claude Code from Anthropic, and
you sign in inside main with your Max plan. Anthropic's rule for a product that preinstalls or runs
Claude Code asks two things: the program is not modified, and none of its ways of signing in is
removed, disabled or restricted.

The options:

- Keep both, always (recommended). Whether or not the rule applies to Silo, Silo never changes
  Claude Code and never limits how you sign in to it. It costs Silo the freedom to patch Claude
  Code, to fix or add something, and to simplify its sign-in in a computer.
- Keep them only if the rule is found to apply. It costs a design that rests on a reading nobody has
  confirmed, while Anthropic says it may act without notice.

Recommended: keep both, always. Silo plans neither change, so keeping them costs nothing now, and
whether the rule applies no longer matters for them.
