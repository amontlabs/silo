# An agent program's own account, checked

## For the owner

An agent's part, 22 November 2026. An agent in main calls the model 40 times with Claude Code's
sign-in, outside Claude Code. Silo sees the 40 calls, Claude Code's own account holds none of them,
and you get an alert.

The options:

- Build it (recommended), as an option you turn on for a computer. It costs a reader for each agent
  program's account, extra work and disk where it is on, and false alerts for a program whose
  account is not yet known to match.
- Leave it out. The 40 calls are still counted and shown. It costs the sign that they did not come
  from Claude Code.

Recommended: build it, after the features you meet every day. It is a check for the computer you
have a reason to doubt, and nothing else depends on it.
