# Import, then install

The owner, on 21 November 2026: "you import it, which allows you to preview it and then you
actually install it and it installs the rules specifically." Installing is agreeing to all the
rules the plugin needs. They are not approved one by one.

Before, this decision said that installing a plugin grants nothing by itself, and that every
grant in it is accepted as a grant.

How a plugin is installed, and how one of its rules is taken back, is the later feature
`installing-a-plugin`.
