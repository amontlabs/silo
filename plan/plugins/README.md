# What you can add

Classifiers that do not ship with Silo: programs that read the record and give opinions.

## For

To let a program made by someone else, or by you, give opinions about a computer, without giving
that program any power over the computer.

## Why it is so

- **An added classifier only gives opinions and asks you questions**
  (`what-a-classifier-gives-back`, `added-classifier-cannot-act`). What follows from an opinion
  is said by a precaution you set.
- **What it reads is a grant** (`reading-is-a-grant`).
- **Where it runs depends on what it is** (`where-a-classifier-runs`,
  `where-a-classifier-runs-is-shown`).

## One example

You add a small model that reads the record of main. It is code, so it runs in a
computer. Reading main is a grant you make, or one a rule you set in advance makes. The model gives
opinions about main and can ask you questions. It cannot pause main, answer an ask or change a
rule. What its opinions lead to is said by a precaution you set.
