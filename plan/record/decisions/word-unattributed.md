# The word "unattributed"

## The choice

An agent's part, 22 November 2026. Main grew by 3 GB today, and two runs are shown to have written
2.2 GB of it. You wrote none of it yourself. Main also reached 14 hosts, and for 2 of them neither
a run nor you is shown to have made the connection.

The options:

- Anything a run can do (recommended). The 0.8 GB and the 2 connections are both unattributed. It
  costs a meaning wider than the promise in force, which speaks only of what runs wrote. Whether that
  promise also counts what you did is asked in `you-or-an-agent`.
- File changes only. Only the 0.8 GB is unattributed. It costs a second word for a connection or a
  spend that nobody is shown to have made.

Recommended: anything a run can do. A receipt already lists what could not be attributed, and a
budget on a run needs the same word for spend.

## Notes

The meaning is worded by whoever wrote the plan, from lines in force. The design record uses the word in a line in force (`books-balance`) and gives it no row in its section 2.
