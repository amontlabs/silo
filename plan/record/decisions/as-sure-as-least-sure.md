# As sure as its least sure ingredient

## The choice

An agent's part, 22 November 2026. Main has a budget of 50 dollars. Silo adds up the spend from the
model calls it saw itself. It also shows that a build wrote 3 GB, added up from what a program
inside main told it.

The options:

- As sure as its least sure ingredient (recommended). The spend counts as a fact, so a rule can deny
  at 50 dollars. The 3 GB is shown as unverified. It costs you the same three levels to keep in mind
  for totals as for single lines.
- Everything computed is an opinion. Any total can be wrong, so only a precaution may act on one. It
  costs budgets, since a budget could no longer be an exact rule.

Recommended: as sure as its least sure ingredient. Adding up facts brings in no judgement, so the
total does not become less sure than what it is made of.
