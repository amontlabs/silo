## Found by an audit, 22 November 2026

An agent's part. This says reads of files are not recorded, and that what entered a model's context
is counted in the model traffic. `patterns-in-the-record`, the owner's wish, and `patterns-of-work`
list "repeated calls, repeated writes and reads". An agent reads the same file twenty times with
`cat`: the record holds no read, so only what entered the model's context again can be listed. The
audit proposes that this entry stays, since a build reads everything, and that the other two say
"repeated calls, repeated writes, the same content entering a model's context again".

The question is put to the owner in `patterns-the-record-shows`, under "The choice".
