# The record under a flood

## The choice

An agent's part, 22 November 2026. An agent creates 2 million files in a loop in main. Before that,
it had reached a host you did not expect.

The options:

- Build it (recommended). The flood is written coarsely: "410,000 files created under target/",
  marked as merged. The line about the host is untouched. It costs detail about the flood itself.
- Leave it out. Every one of the 2 million lines is written until the record is full. It costs disk,
  and then either the older lines or everything after the flood.

Recommended: build it. Making noise must never be a way to erase what came before.
