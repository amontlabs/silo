# File changes in the record

## The choice

An agent's part, 22 November 2026. After a night of work, main is 9 GB larger. You want to know
which files appeared, changed and went, without relying on what the agents say.

The options:

- Build it (recommended). The files a computer created, changed or deleted are in the record as seen
  from outside, so an agent cannot hide one. It costs a comparison of the disk at each checkpoint, 3
  to 22 seconds for 200,000 files in the trials, and a file created and deleted between two
  checkpoints is missed.
- Leave it out. File changes are known only from what programs inside say, which an agent can
  interfere with. It costs Disk, what each run wrote and the files in a receipt.

Recommended: build it. Which files changed is the first thing you ask of a computer you did not
watch.
