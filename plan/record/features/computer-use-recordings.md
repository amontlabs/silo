# Recordings of computer use

## The choice

An agent's part, 22 November 2026. An agent drives the screen of main for 20 minutes to fill in a
form in a browser. No command and no file says what it clicked.

The options:

- Build it (recommended). The record holds a recording of those 20 minutes, with the clicks and keys
  sent. It costs disk: recordings are the heaviest thing in the record, and the first to go at the
  size limit.
- Leave it out. For that stretch the record holds connections and file changes only. It costs
  knowing what the agent did on screen, and the recordings a receipt is meant to hold.

Recommended: build it, when its stage comes. An agent that drives the screen leaves no other trace
of what it did there.
