# A size limit on the record

## The choice

An agent's part, 22 November 2026. Agents drive the screen of main for a few hours a day, and the
recordings add several gigabytes a week. You set the record's limit at 20 GB.

The options:

- Build it (recommended). At 20 GB the oldest recordings go, then the oldest message text, and a
  line says what went. No line is removed. It costs old recordings and old conversation text.
- Leave it out. The record grows until your Mac's disk is full. It costs you deleting Silo's files
  by hand, with no line saying what went.

Recommended: build it. Disk on a laptop is short, and a record nobody can bound gets turned off.
