# Old checkpoints thinned

## For the owner

An agent's part, 22 November 2026. Main has run for three weeks with checkpoints at each turn.
Without thinning, every one of them is still there, each holding what changed after it.

The options:

- Build it (recommended). Old checkpoints are removed by a rule on their age, which you can change,
  and removing one frees the space only it held. An opinion never decides which checkpoint goes. It
  costs moments further back: from last week, one per day stays.
- Leave it out. Checkpoints stay until you remove them. It costs disk on your Mac, until it is full
  and no new checkpoint can be taken.

Recommended: build it. Checkpoints that nobody has to take need an end that nobody has to manage.
