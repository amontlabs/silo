# Drop and the bin

## For the owner

An agent's part, 22 November 2026. On Monday you drop the fork where an agent tried Node 24. On
Thursday you remember a script it wrote there. The fork is still in the bin, and you bring it back.

The options:

- Build it (recommended). A dropped fork or fresh computer waits in the bin for its time there, then
  goes, and only its record stays. It costs disk on your Mac for each dropped computer while it
  waits.
- Leave it out. A drop removes the computer at once. It costs any drop made too soon: what was only
  in it is gone.

Recommended: build it. The Trash on your Mac and the reflog in Git exist for the same reason: a
removal made too soon is common, and cheap to undo for a while.
