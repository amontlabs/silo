# What becomes of a dropped computer

The owner agreed that a dropped computer waits in a bin (STATE, settled). That it can be brought
back for a time is Proposed (record l.1149): the property `dropped-computer-comes-back`, set by
`time-in-the-bin`, which also says how long it stays there and how the bin
is emptied. The feature `dropping-into-the-bin` builds it.
