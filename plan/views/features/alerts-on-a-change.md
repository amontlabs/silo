# Alerts

## The choice

An agent's part, 22 November 2026. At 14:31 a rule sees codex in main send 2.1 MB to paste.rs. At
14:32 the same install reaches 11 more new hosts.

The options:

- Build it (recommended). You get one alert for paste.rs and one for the 11 hosts with a count, and
  opening one takes you to that moment on the Timeline, with the reply that led to it. It costs
  alerts held to a strict line, so a rule that is triggered often still reaches you once.
- Leave it out. Rules and precautions act, and you find what they did in the record. It costs
  hearing about it in time: a host that got 2.1 MB of your data is found the next time you look.

Recommended: build it. Rules and precautions that alert you are worth little until the alert reaches
you and opens on what caused it.
