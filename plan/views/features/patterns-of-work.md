# Patterns of work

## The choice

An agent's part, 22 November 2026. Over a week, `npm install` ran 41 times in 12 runs in main, for 3
h 10 and 9 GB. In one run, the same 4,000-line file was given to the model 20 times.

The options:

- Build it (recommended). A list ranked by cost puts the 41 installs first, with their time and
  disk, then the 20 sends of the file with their dollars. A map shows which paths several runs write
  now. It costs a place you visit now and then rather than every day, and opinions on what counts as
  a repeat.
- Leave it out. You notice repeats in receipts, one run at a time. It costs the patterns that span
  runs, which is where most of the waste is.

Recommended: build it. You asked for the record to be a ground for noticing and improving how agents
work, and this is that place.
