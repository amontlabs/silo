# Network

## The choice

An agent's part, 22 November 2026. Over a day, main reached 40 hosts. One of them, paste.rs, was
new, and codex sent it 2.1 MB.

The options:

- Build it (recommended). One line per host across runs, with how much was sent, the secrets used
  and what was spent, and paste.rs marked as new, with a way to deny it. It costs content shown only
  where Silo reads the traffic; for the rest you see the sizes.
- Leave it out. You learn of new hosts from alerts and read receipts run by run. It costs the view
  of a whole computer: what main sent, and to whom, over a day.

Recommended: build it. Where data went is the first question once an agent holds a secret, and this
place answers it for a whole computer.
