# Now

## The choice

An agent's part, 22 November 2026. You come back after lunch. In main, claude #1 has worked for 1 h
12 and spent $6.40, codex waits on a command, and claude #2 has been stuck on `sleep 600` for 38
minutes. A fork runs a fourth agent.

The options:

- Build it (recommended). One line per run, with its state as Silo's opinion and what it spent, and
  subagents under their run. It costs a place that keeps up with every run of every computer, and a
  state that is sometimes wrong.
- Leave it out. You learn how runs are doing from each agent's own app, one at a time. It costs the
  view across agent programs and computers: a stuck run in a fork you are not looking at goes
  unnoticed.

Recommended: build it. It is the one place that shows every run at once, whichever agent program
started it.
