# Three levels

## The choice

An agent's part, 22 November 2026. An agent in main asks to reach api.stripe.com. The first screen
says main needs you, its line lets you allow or deny, and opening it shows the Timeline at that
moment.

The options:

- Build it as a feature. Three levels become a feature of their own, built and checked on every
  view. It costs a second design of what the first screen already does.
- Leave it out (recommended). The app already works this way: the list of what needs you is the
  status, each line can be answered in place, and each line opens a place with the detail. It costs
  nothing, as long as each new view keeps the three levels.

Recommended: leave it out. The first screen you decided on is these three levels.
