# Comments to the agent

## The choice

An agent's part, 22 November 2026. In the receipt of codex's run you see that it changed `auth.ts`
in a way you do not want, and you want to tell it "keep the old token check".

The options:

- Build it. You write the comment on the change in Silo, and Silo sends it into codex's
  conversation. It costs a second place to talk to agents beside their own apps, and a way into each
  agent program's conversation, which differs from one program to the next.
- Leave it out (recommended). From the run, you open its conversation in your agent app and write
  there. It costs one switch of window.

Recommended: leave it out. You said that working with the agents is the job of the client app, such
as T3 Code, and Silo's window is where you see the work.
