# What you see

The Mac app and the `silo` command: what needs you, and four places to look.

## For

To let a person see in a minute what needs them and what agents did, without reading everything
that happened.

## Why it is so

- **The first screen** (`first-screen`).
- **Facts, reports and opinions are told apart on screen** (`kinds-look-different`,
  `never-shown-as-a-fact`), because a report can be interfered with and an opinion can be wrong.
- **Lists ranked by cost, and a tree for subagents** (`patterns-ranked-by-cost`,
  `subagents-as-a-tree`), so that what costs the most is what is seen first.
- **No logic in the app** (`mac-app-language`), and the same content for programs
  (`silo-command-reads-the-app`), so that an agent and a person read one record.

## One example

An install ran 41 times in 12 runs. It shows as one line in a list of patterns, with its total
time and size, above the patterns that cost less.
