# Can a computer reach more than what was granted

## The choice

An agent's part, 22 November 2026. You make a new computer and start an agent in it. Before you
allowed anything, it needs its model provider and the npm registry.

The options:

- Nothing without you (recommended). A computer reaches only what you, or a rule you set, grant, the
  model provider included. It costs a first step on every new setup, which a set of rules switched
  on at once can shorten.
- A starting list from Silo. A new computer reaches model providers and package registries without
  your yes. It costs ways out you never chose: a registry also accepts uploads, so data can leave
  through it.

Recommended: nothing without you. It is the one sentence the rest of this part stands on, and a
default list would be a grant made by Silo and not by you.
