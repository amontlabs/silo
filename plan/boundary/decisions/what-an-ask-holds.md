# What does a pending ask hold

## For the owner

An agent's part, 22 November 2026. Three agents work in main. One of them pushes to a host that a
rule holds, and the ask waits for you while you are at lunch.

The options:

- Only that request waits (recommended). The push waits, and all three agents keep working. It costs
  you an agent that goes on without the answer and may look for another way to do the same thing.
- The computer pauses. Nothing in main moves until you answer. It costs the two other agents their
  time, for a request that was not theirs.

Recommended: only that request waits. Main is where all your agents work, so one question must not
stop them all.
