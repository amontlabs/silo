# What may the reason in a refusal say

## For the owner

An agent's part, 22 November 2026. An agent in main is refused twice in a morning. First a rule
denies a package published yesterday. Then a classifier you installed denies a command it finds
suspicious.

The options:

- Rules say why, precautions do not (recommended). The first refusal says the package is younger
  than seven days. The second says only that it was denied, unless you let that precaution say more.
  It costs an agent that does not know why the second one failed and may stall or try again blindly.
- Every refusal says why. It costs the classifier its use against a hostile agent, which learns what
  to reword to get past it.
- No refusal says why. It costs turns and tokens on the first case, where one plain sentence would
  have sent the agent the right way.

Recommended: rules say why, precautions do not. A rule cannot be talked around, so naming it is
free. A classifier can be, so its reasons stay with you unless you choose otherwise.
