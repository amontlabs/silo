## Found by an audit, 22 November 2026

An agent's part. `new-host-raises-an-alert` says a host seen for the first time raises an alert, and
`alert-only-on-a-change` says Silo never sends a stream of every event. `network-rules-from-use`
runs main open for a while, and one package install reaches 200 hosts for the first time: 200
alerts. The audit proposes that `alert-only-on-a-change` adds "alerts of one kind in one computer
arrive as one alert with a count". The other way is a new decision that sets the property again as a
rule that ships with Silo, switched on, which you can switch off or narrow.

The question is put to polarzero in `new-host-alert-is-a-rule`, under "The choice".
