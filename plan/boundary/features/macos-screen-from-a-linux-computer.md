# A macOS screen reached from a Linux computer

From the list of smaller features the owner put on the roadmap on 21 November 2026. The owner's
words on the list are in `silos-own-extensions`.

The need: the code and the agent are on Linux, and what must be tried runs only on macOS.

## An agent's notes

- It is a channel between two computers, like `files-between-computers`. Opening it is granting, so
  you or a rule does it.
- `agents-drive-the-screen`, taken, is about an agent inside the macOS computer. Here the agent is
  in another computer.
- Apple allows two macOS computers running on one Mac. With a macOS main, the screen is main's or
  that of one macOS fork, and the agents in main may be using main's screen (`when-a-fork-is-made`).
- How the iOS simulator is reached without the whole screen is to find out.
- It is a channel, so it is part of Silo and not an extension.
