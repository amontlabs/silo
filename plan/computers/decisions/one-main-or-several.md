# Does a user have one main or several

Several would be one per client, or one per level of trust. The research has signs for several.

The taken decision `main-and-its-agents` says there is one main. Several would change it.

## The choice

An agent's part, 22 November 2026. You work for two clients and want their code and their logins
kept apart. polarzero decided that there is one main, and this entry still asks whether there are several.

The options:

- One main (recommended). Your decision stands and this question is closed. Separate work goes in
  other computers beside main. It costs a long-lived main of its own for each client.
- Several mains. You get one main for each client or each level of trust. It replaces your decision,
  takes more of the few computers a Mac can run, and makes every screen ask which main.

Recommended: one main. Everything planned so far assumes one main. A real need for several can
replace the decision later, with its case.

## Found by an audit, 22 November 2026

An agent's part. `main-and-its-agents` says "There is one main computer", `the-shape` and the word
`main` say the same, and this entry still asks whether a user has one or several. `plan` shows it as
undecided, and `computers-main-on-a-mac` needs it. The audit proposes the answer "One, as
`main-and-its-agents` says", so that it can be taken or dropped. A wish for several mains then comes
as a decision that replaces `main-and-its-agents`, with the case for several (one per client, one
per level of trust) in its notes.
