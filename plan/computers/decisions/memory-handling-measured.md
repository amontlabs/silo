# Is memory handling a point where Silo is better than the alternatives

## For the owner

An agent's part, 22 November 2026. You want memory to be one reason people choose Silo. Main and a
Linux computer have been idle for an hour after a build, and someone asks how much memory they still
hold compared with OrbStack or Tart.

The options:

- Measured against other tools, claimed only where shown (recommended). One published benchmark runs
  the same work in Silo and in Apple's `container`, OrbStack, Docker Desktop, Lima and Tart, for
  each release. It costs keeping those tools running the same work, and silence where Silo is not
  ahead. For macOS computers, Apple gives memory back only in a limited way, so Silo may not lead
  there.
- Silo's own numbers only. Silo publishes what its computers hold, with no comparison. It costs the
  point you want to make, since nothing then shows that Silo does better.

Recommended: measured against other tools. Only a comparison can make memory a reason to choose
Silo, and a claim people can check holds up when they do.
