# Is what Silo sees of a computer the same on macOS and Linux

## For the owner

An agent's part, 22 November 2026. Main is a Linux computer, and a macOS computer beside it builds
your iPhone app. Both records show every connection, model call, spend and checkpoint in the same
way, since Silo sees those from outside. Which process changed /work/app/Info.plist is told by a
program inside each computer, and on macOS nobody knows yet whether that works without a click.

The options:

- The same from outside, the rest per system (recommended). Silo says plainly that what it sees from
  outside is the same on both systems, and that what comes from inside can differ. It costs a record
  of a macOS computer that may show less for a time. Which files changed on a macOS computer is also
  not tried yet.
- The same record on both, promised. It costs a promise nobody knows how to keep: no trial has shown
  that a macOS computer can say which process changed a file without a click.

Recommended: the same from outside, the rest per system. It is what `one-kind-of-computer` asks,
with differences only where the system forces them, and it promises only what is known.

## Notes

What can be seen on each system is settled row by row, each row in its own part. The rows of
this part: memory given back when idle (`memory-given-back`), containers inside
(`containers-on-macos`), and the image (`computer-image`).
