# Main on your Mac

## The choice

An agent's part, 22 November 2026. You install Silo on your Mac. Main is a macOS computer where
three agents work at once in `~/work/app` and `~/work/site`. Your Mac's files, keychain and SSH keys
are not in it, and a file goes in or out only when you grant it.

The options:

- Build it (recommended). Your agents get a Mac of their own that lasts, and everything else Silo
  does starts from it. It costs the first run, which downloads and installs macOS, and the memory
  and disk main holds on your Mac. Apple allows one more macOS computer running beside it.
- Leave it out. It costs the product: every other feature of this stage, from forks to the record,
  needs main.

Recommended: build it. It is the first thing Silo is for.
