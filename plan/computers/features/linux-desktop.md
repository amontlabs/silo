# A desktop in Linux computers

## The choice

An agent's part, 22 November 2026. An agent tests your web app in Firefox on Linux, clicking through
it as a person would, in a fork of a Linux computer, and you follow it in a window. Three such forks
run at once, which macOS computers cannot do on one Mac.

The options:

- Build it (recommended). Linux computers can have a desktop that agents drive and you see. It costs
  disk and memory for each Linux computer with a desktop, and the work to show its screen smoothly,
  which is still to find out.
- Leave it out. Only macOS computers have a screen. It costs the limit of two at a time for every
  agent that works through a screen, and it goes back on what you decided: that agents drive a Linux
  desktop as well as a Mac screen.

Recommended: build it, in its later stage. Agents that test through a browser or a screen are
common, and Linux screens are the ones a Mac can run several of.
