# A computer that stops by itself

## For the owner

An agent's part, 22 November 2026. At 3:00 main stops by itself while three agents work in it. Silo
starts it again in seconds, and in the morning an alert says what happened and which runs ended.

The options:

- Build it (recommended). Main comes back by itself, and after three quick failures in a row it
  stays stopped and tells you why. It costs you resuming the agents' conversations, since Silo
  starts the computer and not the agents.
- Leave it out. A computer that dies stays stopped. It costs main's time: it stays down until you
  notice.

Recommended: build it. Main is meant to last, and it should outlast a crash.
