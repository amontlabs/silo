# Where Claude Code comes from

## For the owner

An agent's part, 22 November 2026. Your recipe for main includes Claude Code at version 2.1.0. The
first time Silo builds that recipe on your Mac, it downloads that version from Anthropic and checks
it, and every computer made from the recipe starts with it.

The options:

- Downloaded from Anthropic, pinned by the recipe (recommended). It costs a download from Anthropic
  the first time a recipe is built. The build fails when Anthropic cannot be reached or no longer
  serves that version, and Silo says which download failed and why. Claude Code stays at that
  version until the recipe moves it on.
- Installed by Anthropic's own installer, inside each computer. Each computer gets the latest
  version and updates itself. It costs identical computers: two computers made a day apart run
  different versions, and a version Silo has not checked can break taking a conversation up again in
  a fork.

Recommended: downloaded and pinned. Claude Code's licence reserves all rights, so Silo cannot ship a
copy, and a pinned version is one Silo has checked.
