# A blank computer

## The choice

An agent's part, 22 November 2026. You make a Linux computer and pick no recipe. It holds Ubuntu and
nothing more: no agent program, no Node, none of your tools.

The options:

- Blank (recommended). What a computer holds beyond its system comes only from a recipe you can
  read, and a task that must run on a clean machine gets exactly that. It costs a step, since an
  agent can do little in it until you pick a recipe, which Silo offers when you make a computer.
- A default set. With no recipe, Silo puts in a set of its choosing, such as Claude Code, git and
  Node. It costs the clean machine: a computer you wanted bare is not, and what it holds changes
  when Silo changes the set.

Recommended: blank. In Silo's shape, fresh computers serve tasks that must run on a clean machine,
and only a blank one is clean.
