# Recipes and tasks

How a computer is made, and how a command runs in one until it ends.

## For

To get a whole working computer without setting it up by hand, and to run work in a computer that
needs no setup first.

## Why it is so

- **Where a recipe is kept** (`recipe-stored-by-silo`, `no-project-folder`).
- **What a recipe is for** (`what-a-recipe-sets-up`).
- **Tasks** (`tasks-start-ready`).

## One example

You start a task from a checkpoint of main. It has no setup to wait for.
