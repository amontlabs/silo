# Recipes made of pieces

## The choice

An agent's part, 22 November 2026. Your recipe for main names macOS, Node 22 and three pieces:
Claude Code, Codex and your team's review skill. The skill is written once, and Silo puts it where
Claude Code and Codex each look for skills.

The options:

- Build it (recommended). A recipe is a short list, and a piece written once serves every computer
  and every agent program. It costs Silo the upkeep of where each agent program looks for its
  instructions and skills, which moves when a program changes.
- Leave it out. Each recipe says everything itself. It costs the same lines in every recipe, and a
  skill copied by hand into the folder of each agent program.

Recommended: build it. polarzero asked that recipes be made of pieces, and a short list of pieces is what
makes a recipe quick to write and to read.
