# Computer use with no approval by hand

## For the owner

An agent's part, 22 November 2026. Silo makes a fresh macOS computer for a task that tests your
app's sign-up. An agent opens the app and clicks through it, and nobody had to allow screen
recording or control of the computer.

The options:

- Build it (recommended). Computer use works in every computer made from a recipe that includes it,
  forks and computers for tasks too. It costs a way Apple does not offer, which a macOS update can
  break: the approvals are written with a macOS protection turned off inside the computer. Whether
  it works on the current macOS is still to find out, and the feature waits for that answer.
- Leave it out. You click through the approvals once in each new computer, and its forks keep them.
  It costs computer use in fresh computers made for tasks, since nobody is there to click.

Recommended: build it, once a trial shows it works on the current macOS. The computers where nobody
is there to click are the ones tasks use.
