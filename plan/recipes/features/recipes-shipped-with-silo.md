# Recipes that ship with Silo

## The choice

An agent's part, 22 November 2026. You install Silo and make main from its recipe for macOS with
Claude Code. A new Claude Code comes out on a Monday, and Silo's recipe takes it on Thursday, after
Silo has read what changed.

The options:

- Build it (recommended). You start from a recipe that works, with versions Silo has read for you.
  It costs updates three days after their release, and Silo's own work on every update. Whether
  Anthropic's rule for products that preinstall Claude Code covers such a recipe is still to ask
  Anthropic.
- Leave it out. You write every recipe yourself, or start from your project's files. It costs your
  first hour with Silo, and versions nobody has read for you.

Recommended: build it. Making a computer must be convenient, and a working start is most of that.
