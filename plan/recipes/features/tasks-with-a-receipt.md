# Tasks

## The choice

An agent's part, 22 November 2026. An agent in main starts a task: run the database migration in a
fork of this morning's checkpoint. It ends four minutes later, and you get its receipt, with the
command, its exit code, the 12 files it changed and the hosts it reached.

The options:

- Build it (recommended). Work with an end runs in its own computer, and you judge it from a receipt
  Silo made, not from the agent's summary. It costs a computer for each task, with its disk, and a
  macOS task takes one of the two places for macOS computers on your Mac.
- Leave it out. Agents run such work in main itself. It costs main, which a migration gone wrong
  damages, and you have only the agent's own account of what it did.

Recommended: build it. In Silo's shape, fresh computers serve tasks, and a receipt is how an hour of
an agent's work is judged in a minute.
