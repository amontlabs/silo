## Proposed

- Silo on the user's own device needs no Silo account, sign-up or API key.
- Silo works with no setting touched. Every setting has a default that works.
- Silo works with git and GitHub as they are, and asks a team to adopt nothing beyond them.
- A user who leaves takes each computer as a standard disk image, and each recipe and rule as text.

## Open

- When a user starts, does main copy their agent settings, dotfiles and repositories from the Mac, or start from a guided recipe only? Copying makes the first day fast; a recipe keeps main rebuildable and keeps files from the Mac out of it.
- Can a user try Silo on one project or one task, and leave again without moving anything else? The main path asks them to move their agent into main, which a one-task trial skips.
