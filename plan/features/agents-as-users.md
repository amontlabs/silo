## Proposed

- Every command, output format and doc is designed for an agent as much as for a person.
- An agent's MCP tools are the command line's commands: one definition, with the same names, arguments and output.
- Every capability has a name and a command or a button, even one an agent could do from a prompt alone.
- What Silo gives an agent to act on (a diff, an error, the answer to an approval) is plain text.
