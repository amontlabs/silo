## Proposed

- Silo is complete on one Mac. It needs no hosted service, no server of the user's and no other user, and it works with no server reachable.
- Checkpoints, logs and diffs stay on the device that made them. Copying them anywhere else is always an act the user starts.
- Silo sends no usage or crash data unless the user turns it on, and it lists everything it sends off the device.
- Everything Silo needs on the device ships in its own package. It asks the user to install nothing else.
- When a piece Silo needs is missing or broken, only the feature that needs it stops. A failed GitHub sign-in never stops the computers.
- An expired device link, sign-in or approval never puts data at risk. Logging in again brings everything back as it was.
- No hosted part of Silo opens to other users before it is audited for abuse and runaway cost, and its sign-in and account recovery work.

## Open

- Does everything a hosted part of Silo does have a second path that works without it? It holds for a relay or a sync, but forks on a cloud machine exist because the Mac has no room left.
