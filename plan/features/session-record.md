## Proposed

Why: What went into an agent's context is spread over files that differ per agent program and vanish with the session.

- Rule: The record is kept outside the computer, so a restore or a drop cannot erase it.
- Each record has stable fields: computer, fork, attempt, agent program, how it was captured and how complete it is.
- A fork shows how much context its session used and whether it compacted, where the agent program reports it.
- A computer's page lists the skills, plugins and rules files its agent has switched on.
