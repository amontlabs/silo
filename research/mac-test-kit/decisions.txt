# Which open entry each test answers, and what each outcome leaves possible.
#
# ./kit verdicts and every run's summary.md read this file; ./kit doc writes DECISIONS.md from it;
# ./kit selftest checks it against the tests' outcome lines and the plan. Nothing else holds these
# mappings.
#
#   decision ID                 an entry of the plan, or of a draft named in its source (#NNN)
#     asks: ...                 the entry's question, as the first build needs it answered
#     source: ...               where the entry and its options come from
#     tests: NN NN              every test that bears on it
#     option KEY: ...           its options, the recommended one first (#370 and #373 say which)
#     NN OUTCOME: KEY KEY       the options that outcome of test NN leaves possible
#     NN fact NAME=VALUE: KEY   the same, for a fact the test records
#
# An outcome with no line leaves every option possible: the test gives numbers or facts, not a
# choice. An inconclusive outcome answers nothing. The verdict on an entry is the first option
# every answered test still leaves. A decision with no options is measured, not chosen.

decision network-stack
  asks: What carries main's network in the first build?
  source: plan, open; #370 assumes Apple's NAT until a patched gvproxy passes test 07; #373 needs a stack from main's first start; #363 seals gvproxy with a 64-line patch, which #380 grows into Silo's gvproxy (-sealed, -closed)
  tests: 07 35 36 40 41 42
