Run macOS computers on another Mac and use them from this device. Choose macOS in New computer and pick which connected Mac runs it. Remote macOS computers appear in the Computers list with their device and can be started, stopped, force stopped, deleted and set up again, with progress and logs. Show screen opens a window with the computer's screen that follows the window's size. macOS computers also turn on Screen Sharing during their computer-use setup, which existing computers pick up the next time they start. Checkpoints and clipboard transfer are not available for remote macOS computers yet. Both devices need this version.
