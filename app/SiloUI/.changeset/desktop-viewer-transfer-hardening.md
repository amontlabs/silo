Make file transfers and desktop windows more reliable when shutting down or updating: Quit and logout leave enough time to stop computers, updates let a running file transfer clean up before computers stop, uploads confirm the stored file by its exact name (including names with accented or non-Latin characters), Copy no longer returns an old selection when the computer answers late, and reloading or closing a desktop window no longer leaves sound checks behind.
