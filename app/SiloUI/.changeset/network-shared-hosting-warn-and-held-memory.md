A computer's network list now accepts a `*.` host over a shared-hosting name such as `*.netlify.app` or `*.duckdns.org`, and warns that anyone can publish there, in the network settings and in the approval that adds it. Names a whole registry covers, such as `*.com` or `*.co.uk`, are still refused. Restarting, undoing or restoring a running computer no longer needs free memory for the memory it already holds, only for any extra a larger saved state would take.
