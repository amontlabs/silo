Copy and paste text and images between this device and a computer's Linux desktop. The viewer toolbar has Paste into computer and Copy from computer buttons, Command+V and Command+C do the same on macOS (Ctrl+Shift+V and Ctrl+Shift+C on Linux), and nothing is copied unless you ask. Computers whose desktop predates this release ask you to update the desktop first.
