A personal GitHub token is now a secret. On the Secrets page, Add GitHub token takes a name and the token; Silo checks it with GitHub and shows the account it belongs to, or that it is disconnected. You can add several. On the GitHub page, each computer uses either signed-in access or one of your tokens, chosen by name, so different computers can use different tokens. A token still gives its computer everything it allows on GitHub, and is never shown inside the computer. A token GitHub rejects loses its computers' GitHub access without falling back to anything else. The token you saved before becomes a secret called `github-token` the first time Silo starts, and the computers that used it keep using it. The separate token panel on the GitHub page is gone. A token GitHub cannot be asked about right now (no network, a timeout, a busy GitHub) keeps its last status and is checked again soon; only an answer from GitHub that the token is not valid disconnects it. Going back to an older Silo after you have added a token is not supported: the older version cannot read the secrets file once it holds a GitHub token, and the old single token entry is removed when it moves.
