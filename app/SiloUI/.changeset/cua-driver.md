Computer use in Linux computers now runs on Cua Driver, an open-source tool that comes with the computer image, instead of LCU and ChatGPT for Linux. Silo no longer downloads ChatGPT for Linux, so creating a computer waits only for the computer image, and there is no "Finish without computer use" step. Computer use is set up for Claude Code and Codex; Pi, OMP, Hermes and OpenCode are no longer set up. Cua Driver's usage reporting and update checks are turned off. Until the new computer image is published, new computers download the small Cua Driver package once, from inside the computer. Computers you already have keep working, and Silo frees the disk space of the old ChatGPT and LCU downloads when no computer is running. macOS computers are unchanged for now.
