Several fixes found in review. Opening a merge request while another request is open now shows its changes. The menu bar status now lists waiting requests. Saving a computer's network settings no longer accepts preset updates behind your back; only Accept does, and it shows the hosts it adds. The network settings tell you to read again when they changed under your edit, check hosts as you add them, and use the same checks as the engine. Typing a value in the memory and disk limits no longer saves twice. Text written by an agent in a request can no longer hide or reorder characters, and a request shows the computer's id next to its name. Denying a merge request closes it. Opening an agent on a Mac computer no longer adds a line to your SSH configuration.
