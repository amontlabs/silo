A container computer can use Silo-managed secrets and GitHub access like a Linux computer: the same commands and screens assign them, the computer sees only a placeholder, and the real value is sent only to the hosts you allowed. Ports you publish from a container, and their `silo.localhost` URLs, work too. SSH, the editor, a terminal, the in-guest client and the desktop are still unavailable for containers.
