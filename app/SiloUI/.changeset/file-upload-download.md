Upload files to a running computer and download files from it. In Files, point at a folder and choose Upload files here, or point at a file and choose Download. A name that already exists asks whether to replace the file or keep both. You can also drop files onto the Linux desktop viewer to upload them to the computer's Downloads folder. Transfers show progress, keep running and keep asking questions while you move between pages, can be cancelled, are stopped if a computer sends more than it listed, never overwrite a file that appears while uploading, and need the OpenSSH sftp client.
