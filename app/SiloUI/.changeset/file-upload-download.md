Upload files to a running computer and download files from it. In Files, point at a folder and choose Upload files here, or point at a file and choose Download. A name that already exists asks whether to replace the file or keep both. You can also drop files onto the Linux desktop viewer to upload them to the computer's Downloads folder. Transfers show progress, can be cancelled, and need the OpenSSH sftp client.
