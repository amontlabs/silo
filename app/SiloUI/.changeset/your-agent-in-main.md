Setup now ends with your agent in your main computer. The first computer is suggested as `main`, and a new step, "Your agent", asks which agent you use: Claude Code, Codex, or "I'll set it up myself". Silo installs the one you pick in the first computer while you set up GitHub, and shows the install's progress. If the install fails, setup still finishes: the last screen says the agent could not be installed and offers Retry. When it works, the last screen's main action is "Open Claude Code in main" (or Codex), which opens your terminal on the computer with the agent started in the workspace folder. Silo does not sign in for you; the agent asks for that itself in the terminal.

The same "Open <agent>" action is on a computer's page next to Terminal, in its menu, in the command palette and on its row in the menu bar panel, for each agent installed in it. A computer's Overview has a new Agents section: each agent with its state (ready with its version, not installed, update available, installing, or unknown while the computer is stopped) and an Install or Update button that shows progress and ends in the new state or a plain error. For desktop apps that connect over SSH, Agents and the last setup screen can show the computer's SSH host name on this device with a Copy button; Silo makes the name, and adds it to your SSH configuration, only when you ask for it. The agent you use is remembered (Settings, General), and the form for a new computer offers it as an optional agent that Silo installs once the computer is running. Computers on macOS get their agent after setup, because the engine does not install one while it creates them.
