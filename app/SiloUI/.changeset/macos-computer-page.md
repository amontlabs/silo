A macOS computer is a computer like any other. Open one from the Computers list and it has the same page as a Linux computer: Terminal, Editor and Show screen, Start, Stop and Force stop, Edit CPU & memory while it is stopped, Delete, and the Overview and Checkpoints tabs. The Overview shows its resources, computer use, repositories, secrets and ports. A macOS computer that is still being created or set up shows its progress on its page, with Cancel and Retry setup. macOS computers also appear on the Files (their `/Users/silo/workspace` folder), Logs, Network, Secrets and GitHub pages. They have no Restart, no SSH access for other devices and no Storage tab, and the app no longer offers those. A macOS computer on another device keeps what it had.
