A computer can list its agents and install Claude Code or Codex in it, the same way on Linux and macOS. `agents.list` shows each agent as ready, missing, outdated or installing (unknown while the computer is stopped), with its version. `agents.install` installs one in a running computer from a pinned, checked download and then gives it Silo's computer-use tools straight away. Codex 0.167.0 is the first Codex release Silo ships. Creating a Linux computer can name the agents to install during its first start. Silo never signs in to an agent.
