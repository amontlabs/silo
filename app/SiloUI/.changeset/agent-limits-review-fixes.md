An agent inside a computer is held to tighter limits. When a fork replaces main, the old main's agent can no longer reach the new main or the computers it had made (an undo puts that back). It cannot prepare SSH access or remove your automatic checkpoints, and a new computer larger than its own asks you first. The activity log counts repeated calls in one row, no longer lets a computer's calls push out yours, and shows an agent only the computers it may reach.
