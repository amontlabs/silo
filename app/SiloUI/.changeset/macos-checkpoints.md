macOS computers now have checkpoints. Each set-up computer has a Checkpoints button in its row with the same list as Linux computers: New checkpoint (memory and disk when the computer runs, disk only when it is stopped), Restore (saves a recovery checkpoint first and leaves the computer stopped; Start then continues from the saved memory, or boots from the restored disk with a note when macOS cannot restore it), Fork (a new, independent computer from the checkpoint's disk) and Delete.
